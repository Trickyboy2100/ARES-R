# World view 逐关节折线记录

## 已完成

- 三视图不再用基座到 TCP 的单条点线代替机械臂。
- 单视图画布由 `31×11` 提升到 `91×27`，投影单元数量约为原来的 7.2 倍。
- 按现场方位复核右臂基座旋转：世界轴为北 `+X`、西 `+Y`、上 `+Z`；左/右零位伸展分别为西北/东北，右臂偏航由错误的 `-135°` 修正为 `+45°`。
- 显示 yaw 改用北为 `0°`、俯视顺时针为正：左 `-45°/315°`、右 `+45°`；数学变换角保持独立。
- TOP 和从南向北观察的 REAR 反转屏幕横轴，使西侧/L 位于左边；RIGHT SIDE 保持 R 后绘制并覆盖重合的 L。
- 三张投影增加顶部、底部横向刻度边框，以及左右两侧逐行纵坐标尺，单位为米。
- 每侧折线依次经过基座、J1、J2、J3、J4、J5、J6，再连接 SDK 实时 TCP。
- 关节原点由侧装 JAKA MiniCobo 的公开 MDH 链计算，不使用均分或手绘点。
- 基座和 TCP 使用现场定义与 SDK 只读值；工具 TCP 继续单独显示。
- 35 项自动测试通过，未调用任何运动、使能、复位或夹爪接口。

## 图例与限制

`L/R` 为左右基座，`1..6` 为关节，`l/r` 为左右实时 TCP，`-` 为 MDH 连杆，`:` 为 J6 到实时 TCP。ASCII 栅格有限，投影后重合的关节编号可能互相覆盖。

公开 MDH 的零位总长与现场左臂零位尺度吻合，但 JAKA SDK 2.1.5 未说明 `get_dh_param` 校准量如何叠加到名义模型。该视图仅供姿态理解和排查坐标方向，不得作为轨迹、限位、碰撞或控制输入。

## 操作

```text
./scripts/run_terminal.sh --mode jaka-readonly
world view
```

该模式仅开放状态、基线、世界视图等只读命令。
