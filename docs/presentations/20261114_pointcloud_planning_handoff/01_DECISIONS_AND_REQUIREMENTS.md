## 3. 主线如何落到每页

有真实故障记录：现象/失败位置 → 同帧证据或诊断 → 改了哪个模型、接口、参数或流程 → 同条件复测。

只有模块开发记录：现场需求 → 输入输出与约束接入 → 实现内容 → 已有验证/仍缺证据。不为迎合叙事捏造“原来失败、新方案成功”。

优先案例：

1. 非凸连通结构被整簇AABB过度包络；支撑分层和局部多基元细化；同源点覆盖及体积和对照。
2. 持物模型错误包含料盘下方支撑，PLACE受阻；对象归属与尺寸限定修复；保留环境障碍并从检查点接续。
3. 点云重复查询与稠密核验开销；cKDTree＋原生CPU距离核；输出一致性和历史模块计时对照。
4. 同起终点下实测障碍改变轨迹；不可行场景拒绝输出；规划记录与真实执行记录分开。

## 4. 模板继承的硬约束

从原PPTX实际读取`ppt/presentation.xml`、`ppt/slideMasters`、`ppt/slideLayouts`、主题、关系文件及固定图片。不要新建白底蓝色主题后自称“采用原模板”。

先渲染原模板并记录版式：页面宽高比、标题位置、页边距、固定标志、页脚/页码、分隔线、色板。再在模板内容区重排。模板没有的组件不要自行假定存在。

字体要区分中西文：中文`黑体/SimHei`，Latin`Arial`；辅助中文`宋体/SimSun`、Latin`Times New Roman`。应检查OOXML东亚字体和拉丁字体设置，不能仅改一个run的字体名就认为全部完成。源截图内文字保留原貌；公式不强行改黑体。

字体环境缺失时列出具体缺失与替代渲染影响，不宣称已完全保真。不要向仓库上传字体文件。

## 5. 素材使用决策

原始高分辨率图片/矢量图 > 原PPT中的嵌入图片 > 对原数据重新绘图 > 明确标注的辅助示意。不得把示意、动画、fixture页面冒充实机证据。

同一对照应同视角、同尺度、同坐标范围。显示裁切只用于可读性，不改变碰撞世界；不得裁掉重要障碍却形成误导性安全叙事。

大PPT末尾的“只有同一个标题”的页面很可能是图片素材页。必须实际按页展开并建立“原文件—页码—媒体关系—原始图片—适用新页”映射。

几何对照、性能图、真实视频帧不应全部缩在一页。允许在保持16页的前提下调整每页内容区组合，优先单一主证据图＋短诊断/修改文字。
