## 4. 图形选择的一票否决

- 观众3秒看不见新旧差异，图片不得作为主证据；应该放大同一个ROI并对齐视角。
- 无法确认图像属于哪个快照，就不能标“实验前后”；最多标现场结构示意。
- 对比图必须比较同源输入或明确“不同日期/不同实验等级”。混源截图旁边写别次实验数据导致误导。
- 标注“前处理13簇 vs11簇”不能直接推断识别正确率；结构是否误删须用真实点/目标参考点。
- 无箱/有箱“直线/绕行”是效果，不是方法调参证据；第08和09页要优先呈现12次激活参数和4组seed/CUDA参数。
- 尽量使用PPT原生文本、表格、柱线图；不可把旧60页的窄文字截屏直接贴。
- 分享到public GitHub前审查原PPT的商业、个人与现场信息；只提交可公开的无敏感实验摘要/索引。Mac绝对私人路径不可提交。
