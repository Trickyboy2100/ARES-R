## C档：本地缺失/必须新离线复测（不是简单“后续工作”填附录）

1. **DBSCAN eps/m敏感性**：现有A02固定eps12mm,min8，仅证明3个前置滤波配置。甲方单独点名，若要证明“实验选出12/8”，必须找回真实原始同源点云、冻结其它处理和版本，做例如eps={8,12,16}mm×minpts={5,8,12}并展示有损/保真/时间权衡；保留失败样本，按新日期标注。已有截图不足以重建历史点云。
2. **支撑层×网格细分2×2**：A05是联合变化，不支持单独推断两种因素贡献。使用同一CAMERA源按开关组合重新生成几何，展示定量和局部点/障碍。
3. **某些“由失败到成功”的严格同场景对照**：不把A07和A10或A11拼成同一A/B成功率；可使用A07本身的负例参数曲线作为强证据，辅以后续不同验证等级的工程进展图。

## 核心计算与结论隔离

- 7→167，−58.8%是S21-CLEAR7；32→235，−40.9%是S10-CAMERA；19→405，−68.6%是10/21 GRASP；不能从A03带箱图取数字做同次“前后”。
- 本项目提供的视觉例图并不是本团队训练了YOLO/SAM的证据；不要把别人的训练数据作为“3.2工作量”。
- 激活距离10/20/30/40mm是cost开始起作用的距离，不能被表述成“改成40mm就保证有40mm净空”。A07恰恰证明这不成立。
- 第10/17现场若有两份代码副本不一致，审计按“冻结副本”限定，不能直接断言现场loaded进程必然未接FAST。
- 模型最小间隙、机器人跟踪误差、场景处理耗时和PPT视频播放时间分开计量。
- 同一图片用于另一组运行数字时，必须标“工位/几何示意”，不得在图中画错误对应的可行轨迹。

**参数试验数**（4档×3次；5个速度档；3体素候选；4solver profile；3前置滤波候选）、**问题定位粒度**（212点、局部AABB、哪一段Servo、哪个候选配置）、**代码变更对象**（geometry, robot owner, planner state, native sender, tool mapping, TaskRuntime）、**复测等级**（冻结离线、重复规划、独立world、实时实机、完整跨工位恢复）。
