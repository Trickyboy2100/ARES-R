# PPT母版与精排制作规范｜原生继承，不是类似风格

## 1. 不能妥协的母版

**唯一版式依据**：用户重新上传的 \`生料和水泥的水分细度检验操作目标识别与控制算法研发内部验收20261030V0.95 - 机械臂(1).pptx\`。

必须从该PPT实际文件出发进行编辑/复制页布局和Slide Master/主题，不是按其配色从头画一套假模板。开工先程序化检查：
- \`slide_width/height\`、母版(layout)层次、页脚/页眉/标题/边框/背景/校徽/章节标识/各图框位置；
- 每种可用页型（章节页、内容页、对照页、图表页、成果页）保存缩略图，建立\`template_layout_inventory.md\`；
- 逐页需要的固定组件必须从源模板继承。不能凭印象自行替换其尺寸、位置、角标、页脚或色值；
- 如模板原页嵌入现场图不合适，应保留版式和背景，但在内容区替换素材，不要把不相干旧照片留下占版面；
- 最终16页应是可以和原内部验收PPT连在一起汇报的连续视觉系统。

**前一版问题**：只按照“技术汇报风格”重新绘制，没有真正继承模板/真实图，这就是不合格的核心原因。不可再重犯。

## 2. 字体优先级（用户已明确）

- 中文大标题、二级标题、正文、图内中文：**黑体**为主，英文数字同段使用**Arial**；
- 辅助说明、脚注、引用、必要长备注中文：**宋体**为辅，英文数字辅助使用**Times New Roman**；
- 数学公式**单独处理**：优先原生Office Equation/OMML或清晰矢量公式，不直接使用宋体文本凑数学斜体；中英文字体可在标题、正文、注释各自一致；
- 字号**以母版原有体系为基准**，不自创一个全新的字号系统；可根据真实图所需微调同层级内容密度，但不可为了装下大段文字缩小为不可阅读的小号字；
- 不打包/发布字体文件；使用系统已有合法字体，缺失时在QA报告中明确替代与渲染差异。

## 3. 核心图面模式（在原母版内容版心内安排）

A. **问题截图 + 定位标注 + 修复截图**：最适合P05/P13，源图尽量占整体页面内容区域70%以上；每个图真实源帧/日期统一标注，必要时用细箭头但别画成密密麻麻流程图。

B. **同源参数/点云六阶段中的2–3阶段大图**：最适合P02/P03/P04/P06，原始点云、过滤点、支撑层、局部基元使用等轴或顶视对比；不可放六张过小的高密度细图导致看不清。

C. **真实轨迹三视角+小表/指标条**：最适合P07/P11，路径线颜色/起终点/箱体/真实障碍图例统一。其他变量（起点、padding、工具模型）在页脚“相同”小条注明；照片与GPU轨迹要分别标“PHYSICAL”和“FROZEN”。

D. **一张真实界面/实机画面+一条运行状态示意**：P08/P09/P10/P12，小图流程用母版原生矩形和箭头重建，不能让抽象箭头盖过实物证据。

E. **真实耗时条形图/瀑布图**：P14，各模块注明“历史同输入CPU”、“热规划P50”、“历史任务窗口”三种口径不能混成同一时间叠加。

F. **补证设计页**：P15/P16显著写“**尚未执行｜实验计划，非完成结果**”，测试矩阵留空结果，不能预填成功率或作伪统计曲线。

## 4. 图素材优先权

1. 原用户大PPT最后一批带高清原始Media的备用页（即使没有文本，也要检查PPT slide/media关联和图片预览）；
2. 原内部验收稿中与问题对应的真实现场A/B、实机、机器人截图；
3. 仓库 \`docs/presentations/assets/20261028_rasc_curobo/\` 的源帧可追溯独立PNG/SVG；
4. 第二份小PPT的图注/讲述备注/可编辑框图；
5. 只有缺实景且为了说明软件契约时才用SCHEMATIC原理框图。绝不优先绘制“AI生成假点云/假实机照片”。

图片制作注意：
- 各组旧新对照**同世界轴/同相机角度/同尺度/同膨胀**，日期不能串；
- 图面只保留必要图例、局部放大框、数值三行、一个“结论+边界”小条；
- 不能从PPT母版里直接截取重压缩的全页作为所有背景，使新PPT正文全变不可编辑位图；
- 必须保留图片出处，截图内已有读数/状态/错误信息不应因为裁剪被误导；
- 高清原始截图应选\`ppt/media/*\`原字节而非用低分辨率PPT渲染图二次裁切；
- 不在用户展示的交付PPT中暴露完整路径中可能含个人信息或现场私有网络地址；保留可追溯内部备注。

## 5. 16页建议视觉密度

- P01 研发演进（现场照片主导，少数数字）
- P02–P04 点云（每页2–3张同角度高清，配短数据条）
- P05–P07 几何旧新（图>文字，同源对照）
- P08–P10 规划工业集成（实机/模型/代码契约清晰分层）
- P11–P13 规划对照、真机与真实PLACE故障修复（最醒目的实证页）
- P14 性能前后对照及工作量闭环
- P15–P16 独立补证附页（试验协议，不作为成果）

## 6. 逐页Speaker Notes（强制）

每页放4段：
1. **一句话问题**：这页为什么要做；
2. **修改与工作量**：具体模块/函数/日志怎么发现、处理；
3. **可核数据及复测方法**：同帧/同请求，事实等级，前后对比；
4. **边界和来源**：日期/提交SHA/报告/媒体原页；另备注尚欠哪些数据。

不要把附注内容全塞页面；页面适合投屏，备注用于研发追问和审查。

## 7. 排版与技术质量门槛

- **第一轮设计审查**：按母版抽取布局基准，逐页确认图/表/文字层级、图片不串帧、每页有“做过的具体工作”；
- **第二轮视觉渲染审查**：用LibreOffice或PowerPoint导出16页PDF和单页PNG，制作contact sheet，人工/程序一起看文本框溢出、重叠、图例遮挡、显示乱码、图片裁边、中文/英文字体替代、公式上下标、页码与附页状态；
- 对每个\`pptx\`做ZIP结构验证、\`python-pptx\`可打开、备注非空检查、图像关系完整、字体列表与母版对齐；
- 最终至少交付\`14+2.pptx\`、\`14+2.pdf\`、\`QA_REPORT.md\`、\`MEDIA_PROVENANCE.csv\`；外发媒体和私有日志以审查许可为准；
- 精排不是盲目增加内容：第一页最重要讲范围，第五和第十三页让人看到真实前后图，第十一页让人看到实机避障，最后一页让人看到性能及可复现工作量。

## 8. 固定不改的真实性原则

- 不能把现成开源\`cuRobo\`说成自己编写的GPU优化器；
- 不能给空白附页补“看似实测”的假热力图/失败次数；
- 不能把OLD/NEW都成功的Oct10结果篡改成OLD失败；
- 不能把9/21和Oct10几何数字当同一帧；
- 不能把相机测量指标当整机绝对定位精度；
- 不能把真实P3.7一次避障扩展为通用动态环境安全认证。
