# 抓取、转场与放置如何关联

## 高度由目的任务决定

230mm抬升已有取料测试基础，适合部分高层和专机流程。烘干箱下层要单独设计进入姿态，避免持物或夹爪接近上层隔板。

把“脱离取料工装”“转场持物姿态”“放置入口姿态”分别记录。

| 参数 | 负责阶段 | 含义 |
|---|---|---|
| extraction_profile | Fetch | 脱离原工装所需的方向、距离、姿态约束 |
| carry_profile | Scheme | 转场时实际TCP/关节姿态、持物包络和水平条件 |
| entry_profile | Place | 目的工装入口、preplace、下降/推进和退出 |
| station_binding | 导航 | 地图/SLAM版本、目标站、到站结果 |
| payload_session | 全程 | 对象、夹持变换、工具版本、验证状态和最后实际位姿 |

这些为拟统一合同；当前legacy脚本的参数逐项映射后再接入，不能只改文档就宣称运行已支持。

## 目的地交接表

| 取料 | 目的地 | 抬升与转场处理 |
|---|---|---|
| A0料盘 | B1/B2/B3上层 | 优先复用230mm已验证脱离；另验证持物转场和上层入口 |
| A0料盘 | B1/B2/B3下层 | 原工装脱离量保留物理要求；在净空区规划到LOWER_ENTRY姿态，再进入下层 |
| C0筛网 | D1专机 | 复用230mm筛网脱离和持稳，验证D1入口 |
| A0料盘 | D2专机 | 复用料盘取料链，绑定D2对象与入口 |
| 烘干箱料盘 | A0天平 | 先从槽内退出，再转到CARRY姿态，转场后新鲜检测ID9 |
| D1筛网 / D2料盘 | C0 / A0天平 | 专机取料脱离后持稳，转场后新鲜检测ID8 / ID9 |

LOWER_ENTRY的数值高度待现场几何与规划确认。本版不指定猜测值。必要的高度调整发生在净空区，夹持工具和持物模型随全程传播。

## 典型Scheme

`S-A0-B2-01` 按顺序调用 AA0F0 → 交接/转场姿态 → 已绑定导航路线 → B2到站 → AB2P5 → 返回站。ROS对应 RA0F0 与 RB2P5，通过业务编排接导航。单个ScanPick/ScanPlace不隐含底盘移动。

同一个Fetch用于不同目的地时，Scheme显式选择兼容的handover profile。目标改变导致profile不匹配时，先生成对应持物姿态转换，再交给Place；底盘移动后重建场景。

## 连续五次和反向任务

连续放置任务每轮选择空泊位、预留、抓取、转场、放置、释放确认、提交占用；失败时保留实际持物状态和泊位预留状态。下一轮根据真实结果选择槽位。

从烘干箱取回天平调用对应 BxFn → 转场 → A0P0。抓取完成确认后更新源槽为空，目标放置完成后更新目标状态。任务编号、request_id、payload_session和slot reservation用于关联各步骤。

现有六槽占用表与这些状态的原子提交还需逐项核对实现。手册中的编排为扩展设计，当前不标记已交付。

## 并行边界

允许优先评估SDK/模型预加载、证据异步写盘、下一段参数准备。依赖真实末态的场景、目标和最终轨迹绑定保留在对应时点。底盘与持物机械臂同时运动属于另一个联合验收范围，已成功的串行任务继续作为基线。
