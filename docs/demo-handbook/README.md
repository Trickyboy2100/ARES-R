## 状态含义

| 维度 | 记录内容 |
|---|---|
| 原生实机 | 完整成功、阶段成功、历史成功、仅规划、待验证 |
| 参数绑定 | 当次参数快照及哈希，或当前参数已读但当次哈希缺失 |
| ROS | 未适配、适配/回放、实机调用通过、已交付 |
| 最近运行 | 最近一次成功或故障，独立于历史成功记录 |

Golden 表示明确版本及范围的实机验证结果。ROS 表示通信入口类型。Delivered 表示实际完成交付。Utility 表示功能类别。

## 网页与源码

网页入口为 `/demo-handbook`，左侧目录、页内检索、上一页/下一页和打印可用。源码在 `docs/demo-handbook/`，`catalog.json` 保存目录映射。运行 `python3 scripts/build_demo_handbook.py` 生成 `src/ares_r/webui/demo_handbook.html`。网页为静态阅读页面。
