# Epic Pro 点云识别与抓取位姿验证

## 数据集约定

每个样本目录保存：

```text
runs/vision/<run-id>/
  metadata.json
  raw_response.txt
  detection.json
  point_cloud_reference.txt
  result.md
```

`metadata.json` 至少记录相机序列、相机参数版本、手眼标定版本、空间 ID、物体 ID、模板版本、曝光、点云滤波参数、工件真实位姿、温度状态和 Git 提交号。大型点云保存在外部数据盘，仓库仅记录哈希和路径。

## 精度拆解

总误差按以下链路分别测量：

1. 相机深度噪声与边缘飞点。
2. 点云滤波、裁剪和下采样偏差。
3. 模板匹配位置与姿态残差。
4. 相机坐标到机器人基座坐标的手眼标定误差。
5. TCP 标定误差与夹爪装配误差。
6. 机器人绝对定位误差与负载变形。

仅观察最终抓取成败无法定位误差来源。固定夹具基准点与标定球分别用于相机侧、坐标变换侧和机器人侧测量。

## 最小实验矩阵

- 固定物体、固定相机：连续 30 帧，统计 XYZ 标准差和姿态标准差。
- 固定物体、重启算法图：重复 5 组，检查冷启动偏差。
- 工作区九点：中心、四角、四边，检查空间系统误差。
- 三种高度、三种偏航角、正抓与反抓：检查模板方向偏差。
- 遮挡与反光等级：记录成功率、误匹配率和置信度分布。
- 空场景：统计假阳性。

## 指标

- 平移误差：`||t_detected - t_truth||`，单位毫米。
- 姿态误差：`2*acos(|dot(q_detected, q_truth)|)`，单位度。
- 重复性：同一条件 30 帧的标准差与 P95。
- 可抓取率：通过 IK、碰撞、软限位和奇异门禁的候选比例。
- 首选候选稳定性：连续帧中候选 ID 与抓取方向切换次数。

## 调参顺序

1. 固定相机内参、深度尺度和手眼标定。
2. 清理工作区点云，移除机器人自身、桌面外区域和飞点。
3. 核对模板原点、法向量、抓取点和对称轴。
4. 调整匹配阈值与多候选抑制。
5. 最后调整抓取点偏置；禁止用抓取点偏置补偿明显手眼标定误差。

## 交接产物

- 两个抓取方向的候选位姿及评分。
- 坐标系名称、单位、欧拉角顺序或四元数顺序。
- 标定和模板版本哈希。
- 30 帧重复性统计、九点误差图和失败样本索引。
- 5700 原始返回报文与 ARES-R 解析结果。
