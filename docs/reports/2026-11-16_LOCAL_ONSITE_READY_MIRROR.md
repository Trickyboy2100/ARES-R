# 11月17日现场准备状态

范围为双向关节点镜像、全局车体模型策略、场景显示及简明失败提示。11月16日离场后仅在 Mac 离线准备，未连接机器人或发送运动。

## 实现

- `JointMirrorModel` 根据 pinned ARES 模型和左右 BODY 固定变换，将源臂 J1–J6 中心关于 BODY Y=0 反射，求目标臂近邻关节解。J6 自转不改变关节点位置，因此采用就近解，TCP 朝向不作镜像约束。
- canonical backend 提供双向 HTTP、ART 命令和 WebUI 按钮。解算及路径检查后，以独立原生进程直接调用 JAKA `joint_move`。源臂用独立 actual transport 监测。
- 新版原生程序每进程只连接一个 SDK 控制器，逐臂快照包含实际关节、TCP、tool ID 和 tool data；起点不一致时保留关节、实际值及预期值，不发送 MoveJ。
- 车体禁用依明确全局授权实施。历史定义保留，registered chassis 不再进入 exporter、SceneCompiler、生产 worker 或镜像路径；真实扫描环境障碍仍保留。
- 相机采集默认不要求桌面，不重新拟合相机外参。网页显示 canonical BODY cloud。失败展示短说明，完整原始记录保留。
